Signatur-Baukasten

Vorlage wählen, Text schreiben, Signatur kopieren und in Apple Mail einfügen. Alle Änderungen werden automatisch in diesem Browser gespeichert.

Leerzeile = neuer Absatz. **Wort** wird fett. [Linktext](https://adresse.de) wird ein Link.

Bild unter dem Abspann (optional)

Ein Absender ist ein fester Abspann, z. B. pro Unternehmen, Konto oder Kollegin.

Symbole vor den Kontaktdaten (optional)

Leer lassen = Textbeschriftung (Web, Mail, Tel).

Deine Vorlagen und Absender liegen nur in diesem Browser. Mit der Sicherungsdatei holst du sie auf einen anderen Rechner oder gibst sie einer Kollegin.

Beim Laden werden die aktuellen Daten in diesem Browser ersetzt.

Vorschau

… deine Nachricht …

    1. „Signatur kopieren“ klicken.

    4. Ins rechte Feld klicken, Inhalt löschen, Cmd+V.
